비교 대상: https://wedding-mcard-git-codex-wedding-gard-73c2b9-gdrpaul3-s-projects.vercel.app/guestbook/

원본 공개 화면과 공개 프런트엔드 코드를 읽어 확인한 동작 기준. 원본 방명록에는 쓰기 요청을 보내지 않았습니다.

지도·캐릭터·의상·헤어·장신구·신랑신부는 내장 imagegen으로 생성했습니다. 외부 사진을 앱에 복사하지 않았습니다. 전체 프롬프트는 docs/*-prompt.txt에 보존합니다.

이번 새 리액션·방향별 몸체/머리는 built-in `image_gen`으로 생성하고 `public/assets/poses-v2/raw/`에 원본·프롬프트를 보존합니다. `tools/build_pose_atlas.py`는 배경 정리·프레임 추출·공유 비율 정렬을 수행하며, `manifest.json`의 128px 셀·방향 순서·목 좌표·피부 마스크 계약에 따라 렌더합니다. `tools/review_avatar_poses.mjs`의 오프라인 렌더와 실제 브라우저 검증을 구분해 기록합니다. 사진을 업로드한 이용자 본인의 AI 캐릭터 생성 API 연결과 인터넷 공개 배포는 여전히 미완료입니다.
