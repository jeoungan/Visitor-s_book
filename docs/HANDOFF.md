이전 서버 PID24404가 대화 중단 후 종료되어 PID2648로 복구했던 이력이 있습니다. 이번에는 확인된 PID2648 종료 시 Windows `Stop-Process`의 NullReference 오류가 발생해 PID/포트를 다시 확인한 뒤 .NET `Process.Kill`/`WaitForExit`로 종료하고 PID15132를 실행했습니다. 서버가 종료되면 프로젝트의 원래 서버를 재실행합니다. 미리보기를 살리기 위해 저장 API가 없는 임시 정적 서버로 대체하지 않습니다. 프로세스를 종료할 때는 해당 PID의 경로·명령줄과 프로젝트 관련성을 먼저 확인합니다.

## 완료한 기능과 직전 수정

현재 선택 구성은 의상16·헤어16·장신구15+없음·피부6·동작4(기본 자세/손인사/춤추기/박수)입니다. 서로 다른 부위의 장신구 조합과 기존 색상 옵션을 유지합니다. 새 전체 포즈의 손 앞부분 마스크를 소품 위에 합성해 실제로 쥔 겹침을 보존하고, 좌우/뒤 머리의 밝은 색상에서 남던 검은 패치를 수정했습니다.

이번 `20260920-poses2` 변경과 검증 상태:

1. 모바일 화면을 예식장 중심의 전체화면으로 맞추고 화면 비율에 따라 정원의 배율을 조정합니다. 격리 서버 실제 브라우저에서 390×844와 844×390 모두 Canvas와 뷰포트 크기 일치, 320×568에서 편집창 292×544와 가로 넘침 0을 확인했습니다.
